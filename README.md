# Rajvir Singh Sandhu — Personal Developer Portfolio

A modern, high-performance developer portfolio built with semantic HTML5, modern CSS3, and vanilla JavaScript. Designed with aesthetics inspired by Linear, Vercel, and Raycast (dark mode, crisp typography, subtle ambient glows, responsive layout, and zero heavy dependencies).

---

## 🛠️ How to Run Locally

You can open `index.html` directly in any web browser, or run a local server:

```powershell
python -m http.server 8080
```

Then visit:
```
http://localhost:8080
```
